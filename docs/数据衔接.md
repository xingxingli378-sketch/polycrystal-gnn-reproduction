# 小组自建模拟与公共数据集的衔接

当前 `experiment.py` 读取作者公开的492个微结构，不直接读取小组32³体素模拟。课程版模型已经接入这一公共数据训练入口，但完整自建数据加载、图构建和模拟程序仍待导入。

## 小组模拟需要保留的文件

| 内容 | 建议形式 | 应说明的信息 |
|---|---|---|
| 晶粒ID体素图 | 整数数组 `(Nx,Ny,Nz)` | 32³网格、体素物理尺寸、边界条件、晶粒编号规则 |
| 晶粒欧拉角 | 每个晶粒一行的三列数组 | 弧度或角度、Bunge约定、全局到局部的方向 |
| 节点特征 | 每个真实晶粒一行的五列数组 | 取向、体素数、邻居数；虚拟节点与真实晶粒分开 |
| 邻接关系 | 对称矩阵或边列表 | 共享面的定义、是否周期性邻接、自环由哪一步加入 |
| 外加磁场 | 每个观测的向量或标量 | 方向、A/m或Oe/kOe、单位换算 |
| 有效磁致伸缩 | 每个观测的标签 | 无量纲、ppm/微应变或标准化值，材料常数与平均方式 |
| 模拟记录 | 参数文件及时间序列 | Ms、交换常数、K1/K2、弹性常数、时间步长、停止标准 |
| GNN记录 | 原始预测、权重、划分和归一化参数 | 随机种子、损失、指标、训练轮数、原始单位 |
| IG记录 | 逐晶粒逐特征归因数组 | 基准输入、积分步数、取绝对值和汇总方式 |

## 接入约定

自建样本建议按“微结构编号+磁场编号”记录。所有磁场观测共享相同的微结构分组编号，按该编号拆分训练、验证和测试集。仅在训练集拟合目标归一化参数，再应用于验证和测试数据。

原始标签和标准化标签分别保存。若汇报图使用“Scaled”，应给出转换公式和参数。相对绝对误差应在恢复物理单位后计算：

$$\mathrm{MARE}=\frac{\sum_i|\hat y_i-y_i|}{\sum_i|y_i|}$$

这与逐点百分比误差的平均值不同。若标签本身允许负值，应依据物理任务说明保留规则，不能自动套用公共数据集的负值剔除方式。

归因相关性R²和预测R²分别报告。效率测量注明硬件、预热、重复次数和是否包含构图、数据传输及物理模拟，估算曲线与实测曲线分别标明。
